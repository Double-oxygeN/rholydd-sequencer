# 画面

画面の組み立て、再生の操作、位置の表示、シーケンサーとスペクトラムアナライザー、メニュー、言語、狭い画面、アクセシビリティをまとめます。共有のダイアログとメディア操作は [連携](./integration.md) に書きます。

関係するコード: `src/main.ts`、`src/ui/*`、`src/ui/styles/*`、`index.html`、`src/app-name.ts`、`src/params/reset.ts`
関係するテスト: `tests/interface/screen.test.ts`、`tests/interface/contrast.test.ts`、`e2e/*.spec.ts`

## 振る舞い

### 初期画面

```
[ロゴ] Rholydd Sequencer                                  [共有] [≡]
(▶) [■] 🔈 ───                                  123 小節  4 サイクル
[サイクル内の8bar のメーター（シーンで色分け）                     ]
[8bar 内の2bar のメーター（4マス）                                  ]
[シーケンサー | スペクトラム]
[シーケンサーかスペクトラムアナライザーのどちらか                    ]
状態表示
```

初期画面には、ロゴマークと見出し・再生の操作・音量・累計の表示・2行のメーター・表示の切り替え・共有のボタン・メニューを開くボタンだけを並べます。見出しの左のロゴマークは、アプリのアイコン（`icons/icon.svg`、32px）です。パラメーターとミキサーは、右上のボタンで開くメニューの中です。

### 再生の操作

1つのボタンで再生・一時停止・再開を切り替え、停止のボタンを別に置きます。ボタンの表示と押せるかどうかは、サンプルを読み終えた後は再生の状態の表に従います（[トランスポート](../playback/transport.md#状態)）。読み込み中は画面だけの状態で、再生の状態には含めません。

| 操作 | 読み込み中 | 停止 | 再生中 | 一時停止中 |
| --- | --- | --- | --- | --- |
| 再生のボタン | （押せない。名前は「再生」） | 再生を始める | 一時停止 | 再開 |
| 停止のボタン | （押せない） | （押せない） | 停止 | 停止 |

- 読み込み中は、状態表示に「サンプルを読み込み中…」が出ている間。音量・表示の切り替え・メニュー・共有は、読み込み中も使える
- 読み込み中に押した操作は、読み込みの後に持ち越さない

音量のスライダーは初期画面に置き、マウスを乗せている間と操作している間（キー操作の後は1秒）だけ、つまみの上に百分率を出します。

### 位置の表示

| 要素 | 内容 |
| --- | --- |
| 累計小節数・累計サイクル数 | 再生を始めてから何小節目・何サイクル目か（1始まり）。一時停止をはさんでも続けて数え、一時停止中は止めた位置を保つ。停止中は表示しない |
| サイクルのメーター | 1マスが8bar。マスの数はサイクルの長さ（16・20・24）に合わせ、シーンで色分けし、今の8bar までを点ける。停止中は128bar のサイクルを、まだ来ていない暗いマスで表示する |
| 8bar のメーター | 1マスが2bar の4マスで、今の2bar までを点ける。狭い画面では1マスが1bar の8マス |

### シーケンサー

ステップグリッドの行は、キック・スネア・ハイハット・サブベース・リースベース・スタブの6行です。実音側のイベントを表示します（シーンで抜いたパートの行は空になります）。

- スネアの行には、スネアとゴーストの両方を同じ印で並べる。ゴーストは弱い打音なので、強さの濃淡で暗く見える。実音側でスネアとゴーストが同じステップに重なることはない（重なったときはスネアを描く）
- ドラムの打音は、基準パターン・装飾・フィルを色で区別せず、強さで濃淡を付ける
- 音程のあるパートは、発音の位置と伸ばしている区間を塗り分け、音名はマスの `title` に入れる
- 今のステップを枠で示す。一時停止中は最後に鳴ったステップに残る

### スペクトラムアナライザー

リミッターの後・音量の前の出力を、周波数の帯域ごとのセグメントメーターで表します。

| 項目 | 値 |
| --- | --- |
| 帯域 | 1/2 オクターブ間隔の19帯域（中心 31.5 Hz〜16 kHz） |
| 帯域のレベル | 帯域の端（中心の 2^(±1/4) 倍）の間にあるビンの電力の合計。ビンが1つもない帯域は、中心に最も近いビン |
| セグメント | 1帯域48個、1個 1 dB（−48〜0 dBFS） |
| 補正 | 11.2 dB を足す |
| 色 | −6 dB より上は警告の色、−12 dB より上は注意の色、残りは低い帯域の色 |
| ピークホールド | 帯域ごとに最も高く点いたセグメントを 1 秒保ち、その後 1 秒あたり 24 dB で下げる |

表示していて、かつ再生中のときだけ、毎フレーム描画します。停止中と一時停止中は、すべて消灯した状態を、止めたときと、大きさか配色が変わったときだけ描き直します。シーケンサーを表示している間は大きさが0なので描くものがなく、スペクトラムに切り替えたときに描きます。

### 表示の切り替え

シーケンサーとスペクトラムアナライザーを、2つのタブで切り替えて同じ場所にどちらか一方だけを表示します。初期表示はシーケンサーで、再生中も切り替えられます。

### メニュー

右上のボタンで、右からオフキャンバスのメニューを開きます。メニューの中は、パラメーターとミキサーのタブで切り替えます。初期画面では閉じておきます。

- 背景を暗くせず、モーダルにしない。メニューに隠れていない操作は、開いたまま使える
- 本体の幅を変えず、本体の上に重ねる。幅は `min(640px, 100vw)`
- 閉じるボタン（開くボタンと同じ位置に、メニューより上に重ねる）でだけ閉じる
- パラメーター: BPM、初期キー、変化率3つ、フィル強度、エネルギーの起伏、シード（振り直しのボタン付き）を1行に1つずつ並べる。BPM と初期キーは停止中だけ変えられる
- ミキサー: 音量・パン・センドを切り替えるタブを1つ置き、全チャンネルのスライダーの役割をまとめて切り替える。各行は名前・スライダー・ミュート・ソロ。パンやセンドのないチャンネルは「—」を表示する。下にダッキングの量と戻り時間、マスターのピークとクリップの回数を置く
- 閉じている間もピークとクリップは数え続ける
- パラメーターのタブの最後に「パラメーターを既定値に戻す」、ミキサーのタブのダッキングの下・ピークメーターの上に「ミキサーを既定値に戻す」のボタンを置く

| ボタン | 戻すもの | 戻さないもの |
| --- | --- | --- |
| パラメーターを既定値に戻す | 変化率3つ・フィル強度・エネルギーの起伏 | BPM・初期キー・シード |
| ミキサーを既定値に戻す | 全チャンネルの音量・パン・センド・ミュート・ソロ、ダッキングの量と戻り時間 | 初期画面の音量、調整の対象（音量・パン・センドの切り替え）、ピークとクリップの回数 |

- 既定値は、ページを開いたときの値（設定ファイルにあればその値、なければコードの既定値）
- どの再生の状態でも押せる。効き方は手で動かしたときと同じで、ミキサーは即時に 50 ms で、パラメーターは次にラッチするときに効く
- すべてが既定値のときは押せない状態にする。戻したら、ボタンの横に「既定値に戻しました」と出し、そのタブの値がまた動いたら消す
- 確かめのダイアログは出さず、元に戻す操作も置かない。パンをダブルクリックで中央に戻す操作は残す

### 状態表示

サンプルの読み込み中と、設定ファイルの値を無視したとき（「設定ファイルの一部の値を無視しました（詳細はコンソール）」）に、一言出します。

### 言語

画面を日本語か英語で表示します。ページを開いたときに一度だけ、ブラウザの言語（`navigator.languages`）から決めます。

| ブラウザの言語（先頭から見て、`ja` か `en` で始まる最初のもの。大文字と小文字は区別しない） | 画面の言語 |
| --- | --- |
| `ja` | 日本語 |
| `en` | 英語 |
| どちらもない | 英語 |

- 画面に切り替えの操作は置かない
- `<html lang>` を、決めた言語（`ja`・`en`）にする。`index.html` は `lang="ja"` のまま配り、スクリプトが書き換える
- 対象は、画面に出る文言、アクセシブルな名前と値の言葉、状態表示、メディア操作の表示。コンソールに出す設定ファイルの警告、`config.example.json`、文書、README は日本語のまま。共有したリンクのプレビュー（[連携](./integration.md#共有したリンクのプレビュー)）は、静的なメタデータなので画面の言語によらない
- 言語は画面だけの値で、アンサンブルにもエンジンにも渡さない。生成と音は言語によらない
- アプリの名前、シーケンサーの行の名前、キーの名前（`C♯` など）、BPM、ミキサーのボタンの文字（`M`・`S`）は、どちらの言語でも同じ

### アイコン

再生・一時停止・再開・停止、音量、表示の切り替え、シードの振り直し、共有、メニューは、Lucide のアイコン（`lucide` 1.49.0 に固定）で表します。パラメーターとミキサーのラベルは文字のままにします。

### 狭い画面

幅 320px 以上の画面で、どちらの言語でも横にはみ出さずに全体を表示します。

| 対象 | 広い画面 | 狭い画面 |
| --- | --- | --- |
| シーケンサー | 32ステップを1段に並べる | 幅 560px 以下で、今鳴っている1小節（16ステップ）だけを1段に並べる |
| 8bar のメーター | 2bar で1マスの4マス | 1bar で1マスの8マス |
| スペクトラムアナライザー | 高さ 260px | 同じ19帯域を幅に合わせて細くし、高さを 180px にする |
| ロゴマークと見出し | 見出しは 1.5rem の1行 | 幅 480px 以下で見出しを 1.25rem にし、入りきらなければ単語の間で2行に折り返す。省略もロゴマークだけにもしない |
| 再生の操作と累計 | 1行 | 入りきらなければ累計を次の行に送る |
| メニュー | 右から本体の上に重ねる | 幅 640px 以下で画面の幅いっぱいに広げ、本体を覆う |
| パラメーター・ミキサー | ラベルと操作部品を横に並べる | ラベルの幅を詰め、ミキサーの数値の表示を消す |
| 共有のダイアログ | 幅 480px | 幅 `100vw − 32px`。URL の欄は折り返さずに欄の中でスクロールする |

- ロゴマーク・見出し・共有のボタン・メニューのボタンは、どの幅でも欠けず、互いに重ならない。右上に固定した2つのボタンの分（画面の右端から 100px）を見出しの右に空け、見出しの縦の位置をボタンにそろえる
- 一時停止中は最後に鳴ったステップの小節を、停止中は1小節目を表示する。小節をまたいで伸びる音は、2小節目の頭から続きとして描く
- 1小節を表示するときは、2小節目の頭に小節線を描かず、ほかの拍と同じ線にする

### アクセシビリティ

WCAG 2.2 の適合レベル AA を目安にし、日本語と英語のどちらでも満たします。聴くための操作（再生・一時停止・停止・音量）と、聴き方を変える操作（パラメーター・ミキサー・共有）を、見えなくても、マウスを使えなくても行えることを優先します。

| 対象 | 振る舞い |
| --- | --- |
| Tab キーの順 | 見出し、共有、メニューを開くボタン、（開いていれば）メニューの中、再生の操作、表示の切り替えの順。画面の並びに合わせる |
| タブの並び | 表示の切り替え・メニューのタブ・ミキサーの役割の切り替えは、Tab キーで1回だけ止まり、左右の矢印キーで隣のタブに移って切り替える（端では反対の端へ、Home と End で最初と最後へ） |
| メニュー | 開くと選ばれているタブにフォーカスを移す。閉じた後のフォーカスは開くボタンに残る。開いている間、メニューに完全に覆われた操作部品には Tab キーで移らない |
| 共有のダイアログ | 開くと URL の欄にフォーカスを置き、閉じると共有のボタンに戻す |
| フォーカスの表示 | キーボードの操作では、フォーカスのある部品に 2px の枠を表示する |
| 名前と状態 | アイコンだけのボタンに名前を付ける。再生のボタンの名前は再生・一時停止・再開の表示に合わせて変わる。ミュートとソロは押した状態、タブは選ばれた状態、メニューを開くボタンは開いた状態、停止のボタンと既定値に戻すボタンは押せない状態を伝える。ミキサーのスライダーとボタンは「キック 音量」「キック ミュート」（英語では「Kick level」「Kick mute」）のように、チャンネル名を含めた名前にする。名前は画面の言語で付ける |
| スライダーの値 | 表示と同じ言葉（「30%」「+3 dB」「L20」）で伝える |
| 読み上げ | 状態表示、共有のダイアログのコピーの成否、既定値に戻したことを読み上げさせる |
| ロゴマーク | 飾りとして扱い（`alt=""`）、読み上げさせない。見出しの名前はアプリの名前だけ |
| 図 | シーケンサー・スペクトラムアナライザー・2行のメーターは、何を表すかの名前（「シーケンサー」「スペクトラムアナライザー」「サイクルの位置」「8小節の位置」）だけを伝え、中のマスや帯域は読ませない。位置は累計の文字で伝わる |
| コントラスト | 明るい配色と暗い配色のどちらでも、文字は背景と 4.5:1 以上、操作部品の境界・フォーカスの枠・意味を持つ図形（メーターの点いたマス、スペクトラムのセグメント）は 3:1 以上。シーケンサーの打音と音は、ベロシティの濃淡そのものが表示の中身なので例外とし、比を求めない |

## 実装

### 画面の組み立て（`main.ts`）

```
header（h1（ロゴマークの img と名前の span）、share-toggle、menu-toggle）
aside.offcanvas（メニュー。閉じている間は inert）
controls（再生/一時停止/再開・停止・音量）＋ position の累計
position のメーター2行
views（タブ、シーケンサーかスペクトラム）
p.status（role="status"）
dialog.share
```

- 共有とメニューのボタンは `position: fixed` で右上に置くが、文書の上では見出しの直後に置く。メニューは開くボタンの直後に置き、開いたら次に Tab で進む先にする
- 再生の操作は、画面のボタンとメディア操作の両方から `run(command)` を通し、`render()` が画面とメディア操作の表示を同じ状態で描き直す
- 起動の最初に設定ファイルを読み、ストア・パネル・エンジンを作る（[連携](./integration.md#設定ファイル)）
- 起動の最初に画面の言語を決め、`document.documentElement.lang` を設定し、文言の表を各部品に渡す。ブラウザの値は `location` と同じく `main.ts` だけが読む

### 文言の表（`ui/messages.ts`）

```ts
interface Messages {
  readonly play: string;
  // …
  readonly channel: Readonly<Record<ChannelId, string>>;
  readonly channelControl: (channel: string, control: string) => string;
  readonly barCount: (bar: number) => CounterText;   // 数の前と後の文字列
}
const JA: Messages;
const EN: Messages;
type Language = 'ja' | 'en';
function pickLanguage(languages: readonly string[]): Language;
```

- 数や名前を含む文言は関数にする。言語によって語順が変わるため（「キック 音量」と「Kick level」、「123 小節」と「Bar 123」）。累計は数を強調する要素で包むので、数の前と後の文字列を返す
- チャンネル・タブ・ミキサーの調整の対象のように ID ごとにある名前は、ID を鍵にした `Record` にする。両方の言語が同じ `Messages` 型なので、片方の言語にしかない文言は型の検査で見つかる
- 部品の中には日本語の文字列を置かない（`tests/quality/conventions.test.ts` が確かめる）

| モジュール | 役割 |
| --- | --- |
| `ui/controls.ts` | 再生・停止のボタンと音量。`PlaybackState = 'playing' \| 'paused' \| 'stopped'` から表示を決める |
| `ui/playback.ts` | 再生の状態と操作から、実行する命令（`start`・`pause`・`resume`・`stop`）を決める |
| `ui/position.ts` | 累計と2行のメーター |
| `ui/grid.ts` | ステップグリッド。各マスに `data-bar` を、グリッドに今の小節の `data-bar` を持たせ、狭い画面ではメディアクエリでほかの小節のマスを隠す |
| `ui/spectrum.ts` | 帯域のレベル・点灯数・ピークホールドの計算（Node.js でテストする）と、`canvas` への描画 |
| `ui/views.ts` | 表示の切り替え。各表示をタブのパネルで包む |
| `ui/tabs.ts` | タブの並び（`createTabs`）。選ばれたタブだけを `tabindex="0"` にし、矢印キーで移る。`aria-selected`・`aria-controls`・パネルの `aria-labelledby` を付ける |
| `ui/menu.ts` | オフキャンバスのメニュー。開いたときと、開いている間に画面の大きさが変わったときに、メニューの外の操作部品のうち、横の範囲がメニューの最終位置に収まるものを `inert` にし、閉じたら戻す |
| `ui/panel.ts`・`ui/mixer.ts`・`ui/ducking.ts`・`ui/level-meter.ts` | パラメーター、ミキサーの表、ダッキング、ピークメーター |
| `ui/reset.ts` | 既定値に戻すボタン。戻す値と既定値との一致は `params/reset.ts` の `resetValues`・`isReset` が、ストアの `initial`（ページを開いたときの値）から決める。押せない状態は `aria-disabled` で伝え、押されても何もしない。一言は `role="status"` の要素に出す |
| `ui/dom.ts` | ラベル付きの欄（ラベルは項目名だけを `aria-labelledby` で指し、横の値を名前に含めない）、スライダー、値の表示（`aria-valuetext` を同じ言葉にする） |
| `ui/icons.ts` | アイコンだけのボタン。アイコンと名前を一緒に替える |
| `ui/messages.ts` | 画面の文言の表 `Messages` と、日本語の `JA`・英語の `EN`、`pickLanguage(languages)`。`main.ts` が `navigator.languages` から表を選び、各部品に作るときに渡す |
| `ui/share.ts`・`ui/media-session.ts` | 共有のダイアログとメディア操作（[連携](./integration.md)） |
| `ui/styles/*.css` | `tokens.css` の配色の変数と、部品ごとの見た目。`index.css` が記述順に読む |

### 配色

色は `ui/styles/tokens.css` の変数で持ち、明るい配色と、`prefers-color-scheme: dark` の暗い配色を定義します。区切りの線（`--line`）と、操作部品の境界（`--control-border`）を分けています。シーケンサーの打音は、ベロシティの割合だけ `--base` を `--cell` に混ぜ、伸ばしている区間は `--bass` を 40% 混ぜます。

コントラストは `tests/interface/contrast.test.ts` が、`tokens.css` から2つの配色の値を読み、画面の意味を持つ塗り方を1つずつ挙げた表について比を計算して確かめます。

## 決定理由

- **画面を絞る**: 初めて開いた人が説明なしで操作でき、画面が音を聴く邪魔をしないようにするため。変異やフィルの履歴、キー・コード・シーン名の表示はしない
- **読み込み中は再生と停止のボタンを押せなくし、押した操作を読み込みの後に持ち越さない**: 持ち越すと、押してから音が出るまでの間、押したことを伝える表示が別に要るため。読み込み中であることは状態表示がすでに伝えている。AudioContext はユーザーの操作の中でしか始められないので、持ち越すには `Tone.start()` だけを先に呼ぶ分岐も要る
- **読み込み中を再生の状態に加えない**: 再生の状態はセッションの有無と状態から決まる値で、読み込み中にはセッションを作れないため。ボタンの表示だけの状態（`ControlsState`）にとどめ、再生のボタンとメディア操作の命令の表を増やさない
- **ミキサーをメニューに置き、3つ目の表示の切り替えにしない**: シーケンサー・スペクトラムアナライザーと同じ場所で切り替えると、ミキサーを操作している間、その結果をスペクトラムアナライザーで見られなくなるため
- **音量を初期画面に残す**: 聴くための操作で、パラメーターと違って曲の展開とは無関係であり、すぐ手の届く場所にあるほうが便利なため
- **メニューを本体に重ね、閉じるボタンでだけ閉じる**: 本体を縮めると、開閉のたびにシーケンサーのマスやスペクトラムの帯域が伸び縮みするため。値を調整している途中で、再生の操作をしたはずみにメニューが消えないようにするため
- **ミキサーの役割の切り替えを1つにする**: 音量・パン・センドのスライダーを各行に3本並べると、メニューの幅ではどれも短くなる。1つにすると1本に幅を取れ、チャンネルどうしを同じ量で見比べられる
- **パラメーターを1行に1つにする**: メニューは縦に余裕があるので、スライダーに幅を取るため
- **ミキサーの音量だけ dB で表示する**: ミキサーの音量は比で扱うのが一般的で、0 dB（素通し）からの増減が分かりやすいため。ほかの値は百分率で表示する
- **既定値に戻す操作をタブごとのボタンにし、スライダーごとに戻す操作を足さない**: スライダーごとの操作をキーボードで行うには、標準のキー操作にないキーを割り当てることになり、ページ独自のキーボードショートカットを置かない決まり（[考え方](../concept.md#扱わないこと)）に触れる。マウスだけの操作にすると、キーボードでは元の値が画面から分からないので合わせ直せない。パンのダブルクリックもマウスだけの操作だが、戻す先は中央（C）の1つで、表示を見ながら矢印キーでも合わせられるので残す
- **BPM・初期キー・シードと初期画面の音量を戻さない**: BPM と初期キーは停止中しか変えられないので、含めると状態によって戻るものが変わってしまう。シードは展開そのものを選ぶ値で、戻す先に意味がない。音量は展開ともミキサーとも関わらず、初期画面で直接変えられる
- **既定値をページを開いたときの値にする**: 設定ファイルは配布先ごとに初期値を変える手段で、その配布先での既定はそちらの値だから。コードの既定値に戻すと、設定ファイルで決めたミックスまで消える
- **既定値に戻す前に確かめず、元に戻す操作も置かない**: ダイアログはモーダルになり、メニューを開いたまま再生の操作もできる作りと合わない。戻す前の値を持ち続ける取り消しは、設定を画面から保存する機能（[考え方](../concept.md#扱わないこと)）に近づく。押し間違えても、聞こえ方がすぐに変わるので気づける
- **押せないことを `disabled` ではなく `aria-disabled` で伝える**: `disabled` にすると、押した直後にボタンがフォーカスを失い、キーボードでの位置がページの頭に戻ってしまうため
- **ピークとクリップをミキサーのメニューの中に置く**: 閉じている間も数え続けるので、開けば再生を始めてからの値を確かめられる
- **小節単位と32bar のメーターを削る**: シーケンサーが2bar 単位で表示するので、小節ごとのマスは情報を増やさない。32bar の区切りはサイクルのメーターのシーンの色の切り替わりで読み取れる
- **サイクルのメーターの色分けを残す**: 文字のシーン名がなくても、次のドロップが近づいていることを色で読み取れるようにするため
- **ドラムの打音を層で色分けしない**: 何が鳴っているかを見せるのが目的で、どの層から来たかは聴いている人には不要な情報であるため
- **スペクトラムの取り出しをリミッターの後・音量の前にする**: クリップの検出と同じ音を見て、音量つまみで表示が変わらないようにするため。ゲートの後なので、停止中と一時停止中は何も映らない
- **19帯域・電力の合計・48セグメント**: キック・サブベースの低域とハイハットの高域を別の帯域として見分けられ、1帯域の幅がグリッドの列と同じくらいになる数。ハイハットのノイズは数百のビンに薄く広がるので、最大値ではどのビンも下限に届かず高域が点かなかった。下限はピークメーターの下限（−48 dBFS）とそろえた。補正は、ブラックマン窓でフルスケールの正弦波が最大のビンで約 −13.6 dB になり、主ローブの電力の合計で約 2.4 dB 戻るため
- **スペクトラムを `canvas` に描き、毎フレーム描くのは表示中で再生中のときだけにする**: 19×48 のセグメントを要素で持つと、毎フレームのクラスの付け替えが重いため。描画の負荷で音が途切れないようにするため。タブが隠れている間はブラウザが `requestAnimationFrame` を止める
- **止まっている間のスペクトラムを、大きさと配色の変化で描き直す**: `canvas` のピクセル数の調整と配色の読み取りは描くときにしか行わないので、描き直さないと、画面の幅が変わったときに絵が引き伸ばされ、配色を切り替えたときに消灯したセグメントが前の配色の色のまま残るため。再生中は毎フレーム描くので、二重に描かないよう止まっている間だけにする
- **`window` の `resize` ではなく `ResizeObserver` で `canvas` を見る**: 高さはメディアクエリで変わり、表示の切り替えでも大きさが変わる。`canvas` 自身の大きさの変化を見れば、原因によらず拾えるため
- **見出しの左にロゴマークを置く**: ページを開いたときに、タブやホーム画面のアイコンと同じアプリだと分かるようにするため。アイコンの SVG をそのまま使い、画像を増やさない。リンクにしないのは、ページが1つで戻る先がないため
- **狭い画面では見出しを小さくし、それでも入らなければ折り返す**: 省略（…）やロゴマークだけにすると、アプリの名前が読めなくなるため。フォントは端末ごとに違い幅を決め打ちできないので、入らないときは2行にする。システムフォントでの見出しの幅は 1.5rem で 237px、1.25rem で 197px で、幅 320px で使えるのは約 192px だった。以前は見出しが右上のボタンの下に潜り、幅 320px では名前の途中までしか見えなかった
- **共有とメニューのボタンを固定のままにし、見出しの側で場所を空ける**: 見出しと一緒に流すと、スクロールしたときに共有とメニューに手が届かなくなるため
- **ロゴマークを飾りとして扱う**: 見出しの文字がすでにアプリの名前を伝えていて、読み上げが二重になるため
- **狭い画面でシーケンサーを1小節にする**: 32ステップのままでは、幅 320px で1マスが数 px になり、打音を見分けられないため。上下2段に折り返す案は、マスの幅が1段の1小節表示と変わらず、高さだけが倍になるので不採用とした。2bar を一度に見られないのはモバイル表示の制約とする。小節の頭は左端で分かり、2小節目かどうかは累計小節数で分かるので、小節線は描かない
- **狭い画面でグリッドとページの列を `minmax(0, 1fr)` にする**: 暗黙の列（`auto`）のままでは、マスの `aspect-ratio` から決まる最小の幅でページが横に広がるため
- **アクセシビリティの目安を AA にし、音を聴くための操作を優先する**: この音楽アプリでは音そのものが中身なので、見えなくても、マウスを使えなくても、聴く操作と聴き方を変える操作ができることが要るため
- **図の中身を読み上げさせない**: シーケンサーやメーターは鳴っている音を目で見るための補助で、ステップごとに読み上げると音を聴く邪魔になるため。累計の文字も `aria-live` にしない
- **タブで矢印キーと同時に切り替える**: タブは表示を替えるだけで、確定してから効かせる必要がないため。Tab キーで1回だけ止めるのは、タブの並びを1つの部品として扱い、次の部品へ早く進めるため
- **メニューに覆われた部品へフォーカスを移さない**: 見えない部品にフォーカスが移ると、どこにフォーカスがあるか分からなくなるため（WCAG 2.2 の 2.4.11）。メニューの幅と本体の幅の組み合わせで覆われる部品が幅ごとに変わるので、幅で場合を分けず位置で決める。一部だけ覆われた部品は、見えている部分でフォーカスの位置が分かり、マウスでも押せるので残す。狭い画面では本体のすべてが覆われ、キーボードでは実質モーダルになるが、見えている部品はメニューと閉じるボタンだけなので矛盾しない。メニューの位置は滑り込む途中ではなく最終位置から求める
- **共有のダイアログを閉じたらフォーカスを共有のボタンに戻す**: ブラウザによっては、閉じた後のフォーカスがページ自体に戻り、ページ上の位置を失うため
- **フォーカスの枠を自前で描く**: ブラウザの既定の枠は見た目が違い、背景によっては 3:1 を下回るため
- **区切りの線を薄いままにし、操作部品の境界を別の色にする**: 区切りの線まで濃くすると画面が重くなるため。区切りの線は意味を持たない
- **シーケンサーの打音をコントラストの例外にする**: ベロシティの濃淡で強さを見せる表示で、弱いゴーストが地に溶けて暗く見えることに意味があるため。弱い打音を 3:1 に上げるために濃淡を「下限〜100%」に写す案は、実装すると濃淡の幅が狭まって強さの違いが分かりにくくなったので採らない。打音があること自体は、音と、累計・メーターの表示でも伝わる
- **コントラストをテストで確かめる**: 配色を変えたときに手の計算に頼らないため。トークンの組ではなく塗り方で挙げるのは、同じ色がどこに何として使われているかを漏らさないため
- **ブラウザの言語に従い、切り替えの操作を置かない**: 初期画面とメニューに置くものを増やさないため（画面を絞る）。ブラウザの言語は、その人が読める言語の申告として扱う
- **日本語でも英語でもなければ英語にする**: 日本語を読めない人には、英語のほうが読める人が多いため
- **文言を1か所の表に集め、作るときに部品に渡す**: 足し忘れを型で見つけるため。モジュールの変数から読ませないのは、今の部品が必要なもの（ストアなど）を作るときに受け取る形で、テストでも差し替えやすいため。表に移すのを英語を足す前に分けたのは、振る舞いの変わらない変更を既存の E2E テストで確かめられるようにするため
- **コンソールの警告と文書を英語にしない**: 設定ファイルは配布する人が使う道具で、書き方の説明は日本語の文書（`config.example.json`、[連携](./integration.md#設定ファイル)）にしかないため。文書は日本語で書く決まり（[文書の決まり](../README.md#文書の決まり)）
- **アイコンのライブラリの版を固定する**: アイコンの形が更新で変わらないようにするため
