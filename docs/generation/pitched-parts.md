# 音程のあるパート

サブベース・リースベース・スタブ・パッドの、リズムの型、音高、ボイシング、32bar とサイクルの構造との対応をまとめます。コードの表は [和声](./harmony.md)、シンセの音色は [音](../playback/sound.md) に書きます。

関係するコード: `src/generators/line.ts`、`src/generators/pitch.ts`、`src/generators/sub/*`、`src/generators/reese/*`、`src/generators/stab/*`、`src/generators/pad/*`
関係するテスト: `tests/generation/pitched-parts.test.ts`

## 振る舞い

### 共通の規則

| 規則 | 内容 |
| --- | --- |
| コード | その2bar のコード（`chordOf(ctx)`）の音だけを鳴らす |
| ベースの音 | サブベースとリースベースは構成音（ルート・3度・5度・7度）だけを鳴らし、テンションは鳴らさない。借用和音では借用和音の構成音を鳴らす |
| 2bar の頭 | サブベースとリースベースの各2bar の最初の音はコードのルート |
| 音の長さ | サブベースとリースベースは、次の発音の直前まで伸ばす。最後の音は2bar の終わりか、大きなフィルの開始の直前まで。2bar の境界はまたがない |
| 大きなフィル | 32bar の終わりの大きなフィル区間では、サブベース・リースベース・スタブを鳴らさない。パッドは鳴らし続ける |
| 8bar の終わりのフィル | ドラム以外のパートは変えない |
| 型の選択 | A 系の型をサイクルごとに表全体から、B の型を32bar ごとに残りから均等に選ぶ。B の型は必ず A と異なる |
| フレーズ | A 系はサイクルごとに共通の乱数列、B は8bar ごとの乱数列を使う。同じ8bar の反復の2bar は同じ乱数列 |
| ベロシティ | パートごとに一定。既定値は `generation.lines.velocity`（`config.example.json`） |

### サブベース

低域の骨格を作る役割で、主音中心の長めの音にします。細かく動くリズムはリースベースに任せます。

**音域**: すべての音を F1（MIDI 29）〜 E2（40）に折り返し、2bar の最初の音を除いて確率 `subOctaveJumpChance` で1オクターブ上（F2〜E3）に跳躍します。

**リズムの型**: ステップ `s` の発音しやすさは `min(1, 重み[s] + キックへの加点 × (フィルを適用する前のパターンで s にキックがあるなら1))` です。ステップ0 はすべての型でアンカーです。

| 型 | 重み（記載のない位置は0） | キックへの加点 | 弾き直さない位置 |
| --- | --- | --- | --- |
| キック追従（`kickFollow`） | 0: 1.0 | 1.0 | なし |
| ロングサステイン（`long`） | 0: 1.0、16: 0.5 | 0 | なし |
| 先取り（`push`） | 0: 1.0、14: 0.7 | 0.8 | 16 |
| 3-3-2（`tresillo`） | 0: 1.0、6・12・16・22・28: 0.8 | 0 | なし |
| 問いと答え（`callResponse`） | 0: 1.0、24・26・28・30: 0.5 | 0.8 | なし |

**音高**: 構成音を、`generation.lines.subToneWeights` の重み（ルート・3度・5度・7度）で選びます。

### リースベース

サブベースより細かいリズムで中域を動かす役割で、ドロップだけで鳴ります。サブベースの帯域はハイパスで切って重ねません。

**音域**: F2（41）〜 E3（52）に折り返し、跳躍はしません。

**リズムの型**: ステップ0 はアンカーで、ほかのステップの発音しやすさは `重み[s] × E` です。キックへの加点は持たず、キックとの関係はダッキングで整えます。

| 型 | 重み（記載のない位置は0） |
| --- | --- |
| サステイン（`sustain`） | 16: 0.6 |
| 8分ロール（`roll`） | 偶数ステップ: 0.6 |
| シンコペーション（`syncopated`） | 3・6・10・19・22・26: 0.7 |
| 応答（`response`） | 24〜31: 0.5 |

**音高**: 構成音を、`generation.lines.reeseToneWeights` の重みで選びます。

### スタブ

コードを短く切って鳴らす上モノです。

**ボイシング**

| テンション | 並び | 置き方 |
| --- | --- | --- |
| なし | 3度・5度・7度 | それぞれを C4（60）〜 B4（71）に折り返して低い順に並べる |
| 9度・♭9度・11度・♯11度 | 3度・7度・テンション | 3度を C4〜B4 に折り返し、続く音をそれぞれ直前の音より上で最も近い位置に積む |
| 13度 | 7度・3度・13度 | 同上（7度から積む） |

最低音は C4〜B4 にあり、全体の幅は14半音以内です。

**長さ**: 2ステップ（8分）で一定です。

**リズムの型**: アンカーは持たず、2bar に1回も鳴らないこともあります。ステップ `s` の発音しやすさは `重み[s] × E` です。ステップ 4・12・20・28（スネアのバックビート）の重みはどの型でも0です。直前の発音から2ステップ以上離れ、大きなフィルの開始までに2ステップ収まる位置でだけ発音します。

| 型 | 重み（記載のない位置は0） |
| --- | --- |
| 裏拍（`offbeat`） | 2・6・10・14・18・22・26・30: 0.4 |
| 付点（`dotted`） | 0・6・16・22: 0.6 |
| まばら（`sparse`） | 6・22: 0.6 |
| 応答（`response`） | 24・26・30: 0.6 |

### パッド

各2bar のコードを、ステップ0 から32ステップ（2bar 全体）鳴らします。乱数は使わず、進行だけから決まります。同じコードが続く2bar（i – i など）でも、2bar ごとに弾き直します。

**音**: テンションがなければルート・3度・5度・7度、あればルート・3度・7度・テンション。

**音域**: F3（53）〜 E5（76）。

**ボイシング**: 4音の巡回で作る転回形を、それぞれ下から密集して積み、音域に収まるすべてのオクターブに置いたものが候補です。

- 8bar の最初のコード: 転回なしの候補のうち、平均の音高が音域の中央（64.5）に最も近いもの。転回なしが音域に収まらないとき（テンションのあるコードの一部）だけ、ほかの転回形から選ぶ
- 2つ目以降のコード: 低い順に対応させた声部の移動量の合計が最小の候補。同じなら平均の音高が中央に近いもの

テンションのあるコードでも、隣り合う声部が短2度になりません。

## 実装

| 関数（`generators/line.ts`） | 内容 |
| --- | --- |
| `stylePlan(seeds, tag, styles)` | A 用の型を `hash(cycle, tag)` から表全体で、B 用の型を `hash(phrase, tag)` から A 用を除いた残りで、それぞれ1回引いて選ぶ |
| `styleOf(ctx, plan)` | B なら B 用、それ以外は A 用 |
| `motifSeed(ctx, tag)` | A 系は `hash(seeds.cycle, tag, REL[2bar の関係])`、B は `hash(seeds.section, tag, REL[2bar の関係])` |
| `playableEnd(ctx)` | 32bar の終わりの大きなフィルがあればその開始ステップ、なければ32 |
| `chordTone(roll, weights)` | 構成音を重みで選ぶ |
| `legato(starts, end)` | 次の発音の直前まで伸ばした長さを付ける |

| 関数（`generators/pitch.ts`） | 内容 |
| --- | --- |
| `foldPitch(lowest, pitchClass)` | `lowest` から1オクターブの範囲で、そのピッチクラスの音 |
| `stackUp(order, floor)` | ピッチクラスを順に、直前の音より上で最も近い位置に積む |

各生成器は、リズムの乱数列から全32ステップで1回ずつ、音高の乱数列から全32ステップで1回ずつ（サブベースは「音高用」と「跳躍用」の2つずつ）引いてから判定します。サブベースは状態を持たず、`ContextWithDrums` だけから決まります。キックは `ctx.drums.kicksWithoutFill`（フィルを適用する前のキック）を使います。

パッドの生成器は、8bar の最初のコードから `pairIn8` 番目のコードまで、毎回8bar の頭から順にボイシングを決めます（`sectionVoicings`）。2bar ごとに数個の候補を比べるだけなので、状態を持たずに済みます。

各生成器は、選んだ型も返します（`SubLine`・`ReeseLine`・`StabLine`）。B の型が A と異なることをテストで確かめるためです。

## 決めた理由

- **全パートが同じコードの構成音を鳴らす**: パート同士を参照せずに調性の一貫性を保つため（[アーキテクチャ](../architecture.md#決めた理由)）
- **ベースの音を構成音の番号で選ぶ**: 借用和音の構成音は音階の外にあるので、音階上の距離では表せないため。ダイアトニックのコードでは構成音の番号と音階上の距離が一対一に対応するので、同じ乱数なら同じコードの上で同じ音が選ばれる
- **サブベースをキックから派生させる**: キックと低域の骨格をそろえるため。ロングサステインと 3-3-2 はキックへの加点を持たず、ベースがドラムに逆らって動くこともできるようにする
- **キックはフィルを適用する前の位置を使う**: フィルにはキックを消すもの（スネアロール、ドロップアウトなど）があるが、ベースのパターンを保つことを優先するため。8bar の終わりのフィルの有無で、ベースが変わらない
- **大きなフィルでベースとスタブを止め、パッドを鳴らし続ける**: 32bar の区切りを際立たせ、ベースが止まる間に和声を残して次の32bar へのつながりを保つため
- **サブベースに独自の変異をかけない**: A' と A'' のベースは、キックの変異で加点が変わった位置だけが A と異なる。キックからの派生と変奏を二重にかけないため
- **2bar の境界をまたいで音を伸ばさない**: 次の2bar の生成が、直前の音の状態に依存しないようにするため
- **リースベースをハイパスで分ける**: サブベースと最低音域で重ねないため。リースベースの音域は、サブベースの跳躍先と同じ F2〜E3
- **リースベースとスタブの発音をエネルギーに比例させる**: エネルギーの低い8bar で動きが減り、サステインに近づくため
- **スタブからルートを除く**: サブベースとリースベースが鳴らすルートを重ねず、中高域を薄く保つため
- **スタブをバックビートに置かない**: スネアの抜けを妨げないため
- **13度だけスタブの並びを変える**: 3度・7度・13度の順に積むと、7度と13度が長7度離れて全体が2オクターブ近くに広がるため。7度・3度・13度なら1オクターブに収まる。この並びでは、隣り合う音の間隔は最小でも短3度になる
- **パッドのボイシングを8bar ごとに決め直す**: 前の8bar の状態に依存させず、8bar の頭からいつでも同じ結果を再現できるようにするため
- **パッドの候補から短2度を含むものを除かない**: テンションのない maj7 の転回形では、7度とルートが短2度で隣り合う。除くと、テンションのないコードのボイシングまで変わってしまうため。テンションのあるコードでは、巡回で隣り合う組（ルートと3度、3度と7度、7度とテンション、テンションとルート）がどれも短2度にならないことを、全組について単体テストで確かめる
- **ベロシティを一定にする**: パート間の音量差は、ミキサーとトリムで扱うため
