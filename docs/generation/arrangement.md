# アレンジ（サイクルとシーン）

128〜192bar のサイクルでシーンを巡らせる仕組み、シーンごとのパートとエネルギー、主題の共有、ドロップの入り方、サイクルごとの音色の選び方をまとめます。キーの移調は [和声](./harmony.md)、溜めと FX は [FX](./fx.md) に書きます。

関係するコード: `src/structure/arrangement.ts`、`src/structure/scene-parts.ts`、`src/structure/energy.ts`（`sceneEnergy`）、`src/structure/timbre.ts`、`src/structure/conductor.ts`、`src/generators/arrange.ts`
関係するテスト: `tests/generation/arrangement.test.ts`

## 振る舞い

### サイクル

サイクルは32bar を4〜6つ並べたもので、次の4つの部分からなります。32bar の中の A A' B A'' は、どのシーンでもそのまま保ちます。再生はサイクルの頭から始まります。

| 部分 | 長さ | 8bar の割り当て（A, A', B, A''） |
| --- | --- | --- |
| イントロ＋ビルド | 32bar | 「イントロ, イントロ, イントロ, ビルド」か「イントロ, イントロ, ビルド, ビルド」 |
| ドロップ1 | 32bar か 64bar | すべてドロップ |
| ブレイクダウン＋ビルド | 32bar | 「ブレイクダウン, ブレイクダウン, ブレイクダウン, ビルド」か「ブレイクダウン, ブレイクダウン, ビルド, ビルド」 |
| ドロップ2 | 32bar か 64bar | すべてドロップ |

シーンの境界は8bar 境界にあり、ドロップは必ず32bar 境界で始まり、ビルドの直後は必ずドロップです。

**レイアウト**: サイクルの頭で次の3つを乱数で決めます。確率の既定値は `generation.layout`（`config.example.json`）にあります。

| 項目 | 選択肢 |
| --- | --- |
| イントロの長さ | 24bar か 16bar。ビルドはその32bar の残り（8bar か 16bar） |
| ブレイクダウンの長さ | 24bar か 16bar。ビルドはその残り |
| ドロップの延長 | なし（128bar）・ドロップ1だけ（160bar）・ドロップ2だけ（160bar）・両方（192bar） |

### シーンごとのパート

○は鳴らし、×は鳴らさないパートです。

| パート | イントロ | ビルド | ドロップ | ブレイクダウン |
| --- | --- | --- | --- | --- |
| キック | ○ | ○ | ○ | × |
| スネア | ○ | ○ | ○ | ×（最後のフィルだけ鳴らす） |
| ハイハット | ○（最初の8bar は8分の位置だけ） | ○ | ○ | ○ |
| ゴースト | ○（最初の8bar は ×） | ○ | ○ | × |
| サブベース | ○（最初の8bar は ×） | × | ○ | × |
| リースベース | × | × | ○ | × |
| スタブ | × | ○ | ○ | ○ |
| パッド | ○ | ○ | ○ | ○ |

- リースベースはドロップだけに置き、ドロップの「顔」にする。リースベースが聞こえたらドロップだと分かるようにするため
- ビルドではサブベースとリースベースを抜き、低域を空ける。ドロップの頭でサブベースが戻ったときの落差を最大にするため
- ブレイクダウンでは、ハイハットとスタブ・パッドで進行を聴かせる。ドロップと同じ主進行を和声だけで聴かせておくと、ドロップ2で主題が戻ったと感じやすくなる

### イントロ

イントロは、サイクルの頭で新しい主題と新しいグルーヴを提示するシーンです。再生を始めたときも、2周目以降も同じ形で始め、毎回新しい曲が始まったように聞かせます。

| 区間 | ドラム | サブベース | パッド |
| --- | --- | --- | --- |
| 最初の8bar | キック、スネア、8分の位置のハイハットだけ。ゴーストと16分の裏のハイハットを抜く | 鳴らさない | 鳴らす（ローパスが開いていく） |
| 2つ目以降の8bar | すべて | 鳴らす | 鳴らす |

### エネルギー

8bar ごとのエネルギーは、シーンとシーン内の位置で決まるカーブの値から `E = 1 − energyDepth × (1 − カーブの値)` で求めます（[形式](./form.md#エネルギー)）。値の既定は `generation.energy.scene` にあります。

| シーン | カーブの値 |
| --- | --- |
| イントロ | 一定で中くらい |
| ビルド | 単調に増え、最後の8bar でドロップの A と同じ値まで上がる。16bar のビルドでは1つ目がその手前 |
| ドロップ | 32bar ごとに A・A'・B・A'' のカーブ |
| ブレイクダウン | 一定で最も低い |

`energyDepth = 0` のとき、全シーンでエネルギーが1になります（パートの出し入れと FX は残ります）。

### 主題の共有

サイクルの中の32bar は、1つの曲の中の各部分として、同じ主題を共有します。

| 要素 | 決めるとき | 共有する範囲 |
| --- | --- | --- |
| 主進行とその色付け | サイクルの頭。前のサイクルから確率 `m32` で替わる | サイクルの中の A 系 |
| 転換進行とその色付け | 32bar の頭 | その32bar の B |
| 音程のあるパートの A 系の型とフレーズ | サイクルの頭 | サイクルの中の A 系 |
| 音程のあるパートの B の型とフレーズ | 32bar の頭 | その32bar の B |
| ドラムの基準パターン | サイクルの頭と、ドロップの32bar の頭（ドロップ1の最初を除く）で強い変異 | 次に変異するまで |
| キー | サイクルの頭。確率 `m32 × modulationShare` で属調か下属調へ（[和声](./harmony.md#移調)） | サイクルの全体 |
| 音色 | サイクルの頭。パートごとに確率 `m32` で替わる | サイクルの全体 |

サイクルの中のすべてのドロップで、A 系の進行・リースベース・スタブ・パッドが同じ形で戻ります。ドロップごとに変わるのは、ドラムのグルーヴ、B の転換進行と型、大きなフィルの長さ（A'' の最後の2bar で音程のあるパートを打ち切る位置）、キックに従うサブベースのリズムです。

`m32 = 0` のときは、主進行・基準パターン・キー・音色が最初のまま変わりません。音程のあるパートの型とフレーズは、サイクルごとに選び直します。

### ドロップの入り方

ビルドからドロップへの入り方を、最後の1拍（ステップ 28〜31）の扱いだけを変えた4つから選びます。それより前のビルドとフィルは変えません。

| 入り方 | 最後の1拍で鳴るもの | ライザーとハイパスが止まる位置 | パッド |
| --- | --- | --- | --- |
| 無音（`silence`） | なし（リバーブの残響だけ） | 溜めの頭 | 溜めの頭で切る |
| ピックアップ（`pickup`） | ステップ30 のスネア1打だけ | 溜めの頭 | 溜めの頭で切る |
| パッドだけ残す（`padHold`） | パッドとライザーだけ。ドラムとスタブは止める | ドロップの頭 | 鳴らしたまま |
| 溜めなし（`straight`） | すべて（ロールがドロップの頭まで鳴りきる） | ドロップの頭 | 鳴らしたまま |

| ドロップ | 入り方 |
| --- | --- |
| ドロップ1 | 4つから均等に選ぶ |
| ドロップ2 | ドロップ1の入り方を除いた3つから均等に選ぶ |

- フィル強度が0でも、入り方はそのまま効く（溜めはフィルではないため）。ピックアップのスネアも残る。強さは設定の `lines.velocity.pickup` で、フィル強度に従わない
- 溜めの中で鳴ってよいのは、リバーブの残響（リバーブスローを含む）とライザーの消え際、ピックアップのスネアだけ。パッドのリリースは1拍より長いので、再生側で溜めの頭に短いフェードで切る（[音](../playback/sound.md)）

### 音色

リースベース・スタブ・パッドは、パートごとの音色の表からサイクルの頭で選びます。サブベース・ドラム・FX は入れ替えません。

| パート | 表 |
| --- | --- |
| リースベース | `classic`・`wide`・`hollow`・`growl` |
| スタブ | `square`・`pluck`・`bell` |
| パッド | `saw`・`warm`・`glass` |

| サイクル | 各パートの音色 |
| --- | --- |
| 最初のサイクル | 表全体から均等に選ぶ |
| 2つ目以降 | パートごとに確率 `m32` で、前のサイクルの音色を除いた残りから均等に選ぶ。外れたら前のまま |

音色はサイクルの最初の拍から切り替わり、前のサイクルから続く音の余韻は前の音色のまま消えます。シンセの中身は [音](../playback/sound.md#音色) に書きます。

## 実装

### 型

```ts
type LeadSections = 2 | 3;     // イントロ・ブレイクダウンの8bar の数。ビルドは残りから決まる
type DropPhrases = 1 | 2;      // ドロップの32bar の数
type DropLeadIn = 'silence' | 'pickup' | 'padHold' | 'straight';
type DropOrdinal = 'first' | 'second';

interface CycleLayout {        // サイクルの長さは 32bar × (2 + firstDrop + secondDrop) から求め、別に持たない
  readonly intro: LeadSections;
  readonly breakdown: LeadSections;
  readonly firstDrop: DropPhrases;
  readonly secondDrop: DropPhrases;
  readonly leadIns: Readonly<Record<DropOrdinal, DropLeadIn>>;   // 2つは異なる
}

type LeadPosition  = { sections: 2; index: 0 | 1 } | { sections: 3; index: 0 | 1 | 2 };
type BuildPosition = { sections: 1; index: 0 } | { sections: 2; index: 0 | 1 };
type DropPosition  = { phrases: 1; phrase: 0 } | { phrases: 2; phrase: 0 | 1 };

type SceneRole =
  | ({ scene: 'intro' } & LeadPosition)
  | ({ scene: 'build'; leadIn: DropLeadIn } & BuildPosition)   // 直後は必ずドロップ。入り方はそのドロップのもの
  | ({ scene: 'drop'; drop: DropOrdinal } & DropPosition)
  | ({ scene: 'breakdown' } & LeadPosition);
```

### 関数

| 関数 | 役割 |
| --- | --- |
| `drawLayout(cycleSeed, tuning)` | `hash(cycleSeed, TAG.layout)` からイントロの長さ・ブレイクダウンの長さ・ドロップの延長の順に3つ引き、`hash(cycleSeed, TAG.dropLeadIn)` から入り方を2つ引く |
| `cycleScenes(layout)` | サイクルの8bar ごとの `SceneRole` の列。イントロの後のビルドには `leadIns.first`、ブレイクダウンの後のビルドには `leadIns.second` |
| `sceneEnergy(role, sectionIn32, depth, tuning)` | シーンのエネルギー（`structure/energy.ts`） |
| `plays(role, voice)`・`playsHit(role, hit)` | シーンで鳴らすパート。イントロの最初の8bar では、サブベースとゴーストと奇数ステップのハイハットを鳴らさない（`structure/scene-parts.ts`） |
| `changesScene(ctx)` | 8bar の終わりで、次のシーンが今と異なる |
| `leadsIntoDrop(ctx)`・`leadsIntoBreakdown(ctx)` | ビルドの最後の2bar・ドロップの最後の2bar（次がブレイクダウン） |
| `opensDrop(ctx)` | ビルドの後のドロップの最初の2bar |
| `refreshesReference(role)` | ドラムの基準パターンに強い変異をかけるシーン。イントロと、ドロップ1の最初の32bar 以外のドロップ |
| `dropLeadIn(ctx)`・`hasGap`・`silencesGap` | 溜めのある2bar とその入り方。溜めの開始位置は `GAP_START`（ステップ28） |
| `cycleTimbre(previous, cycleSeed, m32)` | リース・スタブ・パッドの順に、パートごとに「替えるかの判定」「音色」の2つを引く。最初のサイクルでも、替えないときも2つとも引く |

コンダクターは、サイクルの頭と長さを保持して進めます（長さが一定でないので、小節の通し番号からサイクルの番号を計算では求められないため）。サイクルの頭（32bar の頭で `m32` をラッチした後）で、レイアウト・シーンの列・主進行・移調の幅・音色を `CycleState` として作り直し、`sectionInCycle` 番目の `SceneRole` と、次の8bar のシーン（`nextScene`）を `Context` に入れます。`sceneRole` と `sectionRole` は、どちらもコンダクターだけが同じレイアウトから作るので、食い違いません。

選別と溜めは `generators/arrange.ts` が行います（[FX](./fx.md#選別と溜め)）。

## 決めた理由

- **ドロップを32bar 境界から始める**: 32bar の区切りを聴き取れる構造の上で、最も強い区切りに最も大きな変化を重ねるため。ビルドを32bar の終わりに置くと、32bar の終わりの大きなフィルがそのままドロップへの導入になる
- **可変長の部分をドロップの延長に充てる**: ドロップは聴かせどころなので、長く浸りたいときと短く切り替えたいときの両方がある。延長したドロップは、2つ目の32bar の頭でドラムのグルーヴだけを変え、主題は続ける。ブレイクダウンを増やす案は、サイクルの中でドロップが3回になると、主題の再現が「聴かせどころ」から「繰り返し」に変わるので採らない
- **イントロの最初の8bar をパートと位置ごと抜く**: エネルギーの間引きでは弱い位置の打音しか抜けず、音数がほとんど減らない（シミュレーションで、エネルギーを下げたイントロの最初の8bar もドロップも、1小節あたり約13打だった）。ゴーストと16分の裏のハイハットを抜くと約8打になる
- **2周目以降もイントロを同じ形にする**: ドロップ2の大きなフィルの後でいったん薄いビートに戻すと、次の曲に移ったことがはっきり伝わる。ドラム自体は途切れさせないので、曲が止まったようには聞こえない
- **ドラムにローパスをかけない**: ドロップから移った直後にドラムまでこもると、曲が止まったように聞こえるため。ローパスは音程のあるパートだけにかけ、新しい主題の和声がこもった状態から開いていくようにする
- **ビルドのエネルギーを単調に増やし、上限をドロップの A に揃える**: 上昇の途中で谷を作らず、ドロップの頭でドラムがビルドより薄くならないようにするため。ビルドの緊張の高まりは、エネルギーよりもライザーとハイパスで作る
- **ドロップで32bar のカーブを使う**: ドロップの中に A A' B A'' の起伏を残し、32bar の区切りを聴き取れるようにするため
- **入り方を4つから選び、ドロップ1と2で変える**: 毎回同じ1拍の無音を挟むと、サイクルを重ねるうちに「次は無音が来る」と読めてしまい、溜めが効かなくなるため。1曲の中で同じ溜めが2回続くと、2回目のドロップの入りが読めてしまう
  - **無音**: 完全な無音から一気に解放する、最も落差の大きい入り方
  - **ピックアップ**: 無音の最後の8分にスネアを1打だけ置き、ドロップの頭の位置を予告する。無音の緊張を残したまま、着地のタイミングを耳で掴めるようにする
  - **パッドだけ残す**: リズムだけを止め、和音とライザーで溜める。スタブも止めるのは、短い刻みが残るとリズムが止まったように聞こえず、溜めにならないため
  - **溜めなし**: ロールとライザーをドロップの頭まで鳴らしきって突っ込む。ほかの3つとの対比で溜めが効く
- **入り方をサイクルの頭でまとめて選ぶ**: ライザーとハイパスの進み具合は、ビルド全体で止まる位置までを 0 → 1 として計算するので、ビルドが始まる前に入り方が決まっている必要があるため。`m32` には従わせない。`m32` はサイクルの頭で何を持ち越すかの量で、入り方はサイクルの中の2つのドロップを対比させるためのものだから
- **ドロップ2を特別に盛り上げない**: ドロップ2の新鮮さは、ドラムのグルーヴの変化と、ドロップ1と異なる入り方で出す（試聴で確定）
- **音色を入れ替える**: 主題・グルーヴ・キーを入れ替えても、どのサイクルも同じシンセの音だと、1時間のうちに「同じ曲の別のバージョン」に聞こえてくる。曲が替わったことを最も直接に伝えるのは音色である
  - リースベースはドロップの顔、スタブはビルドとブレイクダウンで前に出る上モノ、パッドはイントロの最初の手がかりなので入れ替える
  - サブベースは低域の土台で、キックとの釣り合いを音色ごとに崩さないために入れ替えない。ドラムはサイクルをまたいで途切れさせずにつなぐ役なので、グルーヴの変化だけで新しさを出す。FX は「切り替わりの合図」として毎回同じ音のほうが意味が伝わる
  - 音色を連続値の乱数で作らず表から選ぶのは、少しずつ違うだけの音色が続くと変化に気づけず、どの組み合わせでも音量と帯域の釣り合いを確かめられないため
  - パートごとに独立に選び、パレットとして組では選ばない。替えるときに前の音色を除くのは、「替える」と決めたのに同じ音色が選ばれて変化が聞こえない、ということをなくすため。既定の `m32 = 0.6` で、3パートとも前のままになるのは約6%
  - サイクルの頭でだけ替える。イントロの頭ではローパスが閉じていてパッドだけがこもって鳴っているので、切り替えが目立たず、ローパスが開くにつれて新しい音色が現れる。リースベースはドロップまで、スタブはビルドまで鳴らないので、最初に鳴った時点で新しい音色になっている
- **`m32` の1つでサイクルごとの変化を決める**: 主進行・移調・音色・強い変異をすべて `m32` に従わせ、1つのパラメーターでサイクルごとの変化の大きさを決められるようにする
