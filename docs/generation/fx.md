# 選別・溜め・FX

生成した2bar から鳴る側のイベントを作る選別と溜め、シーンの切り替わりを演出する FX のイベントをまとめます。FX をどう鳴らすか（オートメーションと音色）は [音](../playback/sound.md) に書きます。

関係するコード: `src/generators/arrange.ts`、`src/generators/fx/index.ts`、`src/structure/arrangement.ts`（境界の判定）
関係するテスト: `tests/generation/fx.test.ts`、`tests/generation/arrangement.test.ts`

## 振る舞い

### 選別と溜め

1. シーンで鳴らさないパートのイベントを取り除く（[アレンジ](./arrangement.md#シーンごとのパート)）。ただし、ブレイクダウンの最後の2bar では、フィルの層のスネアを残す
2. ドロップの直前の2bar で、入り方が溜めのあるもの（無音・ピックアップ・パッドだけ残す）なら、ステップ28 以降に始まるドラムの打音を取り除き、音程のあるパートのノートを `step + length ≤ 28` に切り詰める。長さが0になるノートは取り除く。パッドだけ残すでは、パッドを切り詰めない
3. ピックアップなら、ステップ30 にスネアの打音を1つ加える

| 入り方 | ドラム | パッド | ほかの音程のあるパート | 加える打音 |
| --- | --- | --- | --- | --- |
| 無音 | 28 未満だけ | 28 で切る | 28 で切る | なし |
| ピックアップ | 28 未満だけ | 28 で切る | 28 で切る | ステップ30 のスネア |
| パッドだけ残す | 28 未満だけ | そのまま | 28 で切る | なし |
| 溜めなし | そのまま | そのまま | そのまま | なし |

ビルドで鳴る音程のあるパートはスタブとパッドだけなので、パッドだけ残すで切るのは実質的にスタブです。

### FX

| FX | 鳴る位置 | 内容 |
| --- | --- | --- |
| ライザー | ビルドの全体 | ホワイトノイズのバンドパスの中心周波数と音量を上げ続ける。無音とピックアップでは溜めの頭、パッドだけ残すと溜めなしではドロップの頭で止まる |
| ハイパスのスイープ | ビルドの全体 | ミックス全体のハイパスを、開いた状態からライザーと同じ位置まで上げ続ける |
| ローパスのスイープ | イントロの最後の8bar の前まで | 音程のあるパートのローパスを、閉じた状態から開ききる |
| フィルターのリセット | ビルドの最後の2bar の終わり（ドロップの頭） | ハイパスとローパスを開いた状態に戻す |
| インパクト | ビルドの後のドロップの頭（ステップ0） | ピッチの下がるサイン波とノイズのバーストを重ねた音。延長したドロップの2つ目の32bar の頭では鳴らさない |
| リバーブスロー | ビルドの後のドロップの直前と、ドロップ1の後のブレイクダウンの直前の2bar | 最後に鳴るスネアの打音1つを、通常のセンドとは別の経路でリバーブに大きく送る。ドロップの直前では、入り方によらずステップ28 より前の最後のスネア |
| 溜め | ドロップの直前の2bar のステップ28 から（溜めのある入り方だけ） | 無音とピックアップでは再生側でパッドを切る（`cut`）。パッドだけ残すでは切らない（`held`） |

スネアが鳴らない（大きなフィルがドロップアウトなど）ときは、リバーブスローは入りません。フィル強度が0でも、溜めとピックアップのスネアとリバーブスローは残ります。

## 実装

### 選別（`arrange(ctx, lines, pickupVelocity)`）

生成側の結果（`ctx.drums`、各パートのライン）は書き換えず、鳴る側のイベント（`EnsemblePair.events`）を新しく作ります。ピックアップのスネアの層は `fill` にします。

### FX のイベント（`fxEvents(ctx, heard)`）

乱数を使わず、`Context` と鳴る側のイベントだけから決めます。

```ts
type StepEnd = Brand<number, 'StepEnd'>;   // 1〜32。区間の終わり（その位置は含まない）
interface FxSpan { to: StepEnd; startProgress: UnitInterval; endProgress: UnitInterval }   // 2bar の頭から

type FxEvent =
  | { fx: 'riser'; span: FxSpan }
  | { fx: 'sweep'; filter: 'lowpass' | 'highpass'; span: FxSpan }
  | { fx: 'impact'; step: Step }
  | { fx: 'throw'; step: Step }
  | { fx: 'filterReset' }                               // その2bar の終わり
  | { fx: 'gap'; from: Step; pad: 'cut' | 'held' };    // その2bar の終わりまで溜め
```

2bar をまたぐ FX（ライザー、スイープ）は、2bar ごとの区間に分けて出します。進み具合は `(シーン内の通しステップ) / (区間全体のステップ数)` で、シーン内の位置（`sceneRole` の `index`、`pairIn8`、ステップ）だけから決まるので、どの2bar から見ても同じ値になります。ライザーとハイパスの区間全体は、ビルドの頭から入り方で決まる止まる位置までです。

| FX | 2bar | 区間・位置 |
| --- | --- | --- |
| ライザー・ハイパス | ビルドの各2bar | 最後の2bar は、`silencesGap` が真の入り方で `to = 28`、それ以外で `to = 32` |
| ローパス | イントロの最後の8bar より前の各2bar | イントロの頭から、最後の8bar の頭まで |
| インパクト | `opensDrop` の2bar | ステップ0 |
| フィルターのリセット | `leadsIntoDrop` の2bar | その2bar の終わり |
| 溜め | `dropLeadIn` が溜めのある入り方の2bar | ステップ28 から |
| リバーブスロー | `leadsIntoDrop` か `leadsIntoBreakdown` の2bar | 鳴る側のドラムの最後のスネア。`leadsIntoDrop` ではステップ28 より前に限る |

## 決めた理由

- **選別を生成器の外で行う**: 鳴らさないパートも生成を続けて乱数列を保つため（[アーキテクチャ](../architecture.md#決めた理由)）。生成側の結果を書き換えないので、シミュレーションで「生成されたもの」と「鳴ったもの」を両方数えられ、生成側の性質を確かめるテストがそのまま保てる
- **ダッキングは鳴る側のキックから取る**: 生成側のキックから取ると、ブレイクダウンでもダッキングしてしまうため
- **溜めをフィルに含めない**: フィル強度が0でも溜めを残すため。溜めを「4ステップのドロップアウト」として作ると、強度0で「大きなフィルが入らない」ことと食い違う。ピックアップのスネアをドラム生成器のフィルに入れずここで加えるのも同じ理由。層を `fill` にするのは、グリッドとシミュレーションで、基準パターンや装飾の打音と区別できるようにするため
- **FX を生成側で決める**: FX の位置と値をシミュレーションと単体テストで確かめられるようにし、再生側は予約するだけにするため
- **FX に乱数を使わない**: シーン内の位置だけから決まるので、どの2bar から見ても同じ値になり、一時停止からの再開でも途中の値を求め直せるため
- **フィルターのリセットをビルドの最後の2bar に置く**: ドロップ側の2bar に置くと、2bar ごとに求める開始時刻の浮動小数の誤差で、リセットが同じ瞬間に終わるハイパスのランプより前に入ることがある。そうなるとランプがリセットの値から閉じ直し、ハイパスが閉じたままドロップが鳴るため、ランプと同じ2bar の開始時刻から求める
- **リバーブスローを最後の1拍より前のスネアにする**: ピックアップや溜めなしのロールの終わりの残響が、ドロップの頭に被らないようにするため
- **インパクトをビルドの後のドロップの頭だけにする**: 延長したドロップの2つ目の32bar の頭は、大きな区切りではあってもシーンの切り替わりではないため
- **ライザーの止まる位置を入り方に従わせる**: 無音とピックアップでは、音が止まった後に残る無音とリバーブスローの残響が溜めになる。パッドだけ残すでは、和音の上で緊張が最後まで上がる
- **周波数を対数的に動かす**: 耳には周波数の比が一定の速さで変わるほうが、一定の速さに聞こえるため
