# 用語集

仕様の文書とコードで使う言葉です。コードの名前があるものは括弧に入れています。

## 時間の単位

| 用語 | 意味 |
| --- | --- |
| ステップ（`Step`） | 16分音符1つ分。2bar の中の位置を 0〜31 で表す |
| 2bar（ペア、`PairIndex`） | 生成の単位。16分×32ステップ。1小節目が問い、2小節目が答え |
| 8bar（セクション、`SectionIndex`） | 2bar×4。反復・反復・反復・変奏の関係を持つ |
| 32bar（フレーズ、`PhraseIndex`） | 8bar×4。A・A'・B・A'' の関係を持つ |
| サイクル（`CycleIndex`） | 32bar を4〜6つ並べた128〜192bar。1曲に当たる |
| 累計小節数・累計サイクル数 | 再生を始めてから何小節目・何サイクル目か（1始まり）。一時停止をはさんでも続けて数える |

## 区間の関係

| 用語 | 意味 |
| --- | --- |
| 反復（`repeat`） | 基準と同じ形。同じ8bar の中の2bar の0〜2番目、32bar の A |
| 変奏（`variant`） | 基準を少しだけ変えた形。8bar の4番目の2bar、32bar の A' と A'' |
| 転換（`transition`） | 基準とまったく違う形。32bar の B |
| A・A'・B・A''（`SectionRole`） | 32bar の中の4つの8bar の役割。A 系は A・A'・A'' |
| 基準パターン（`reference`） | 32bar の A で鳴るドラムのパターン。強い変異でだけ書き換わる |
| 基本パターン（`base`） | その8bar で鳴るドラムのパターン。基準からの変奏、転換、エネルギーの間引きを経たもの |

## ドラム

| 用語 | 意味 |
| --- | --- |
| パート（`Part`） | キック・スネア・ハイハット・ゴースト（ゴーストスネア）の4つ |
| モチーフ（`Motif`） | パートの1周期分のパターン。ハイハットは1拍（4ステップ）、ほかは2bar（32ステップ） |
| 重み表（`PartProfile.weights`） | モチーフの各位置の鳴りやすさ。1 がアンカー、0 が禁止 |
| アンカー | 必ず鳴る位置。変異で消さない |
| 変異 | 発音を足す・消す・動かす操作。8bar 境界の弱い変異（変奏）と、強い変異がある |
| 強い変異 | 基準パターンを書き換える変異。サイクルの頭と、ドロップの32bar の頭で行う |
| 間引き | エネルギーが低い8bar で、弱い位置の発音を鳴らさないこと |
| 装飾（`ornament`） | 2小節目の後半に一時的に足すハイハットとゴースト |
| フィル | 8bar の終わりのテンプレートによる置き換え |
| 大きなフィル | 32bar の終わり（31〜32小節目）のフィル |
| 層（`Layer`） | 打音の出どころ。基本パターン（`base`）・装飾（`ornament`）・フィル（`fill`） |

## アレンジ

| 用語 | 意味 |
| --- | --- |
| シーン（`Scene`） | イントロ・ビルド・ドロップ・ブレイクダウンの4つ |
| レイアウト（`CycleLayout`） | サイクルの中のシーンの長さとドロップの入り方 |
| ドロップ1・ドロップ2（`DropOrdinal`） | サイクルの中の1つ目と2つ目のドロップ |
| ドロップの延長 | ドロップを32bar から64bar にすること |
| 入り方（`DropLeadIn`） | ビルドからドロップへの最後の1拍の扱い。無音・ピックアップ・パッドだけ残す・溜めなし |
| 溜め（`Gap`） | ドロップの直前の1拍（ステップ 28〜31）で、鳴らすパートを絞ること |
| 主題 | サイクルの中で共有する、主進行と音程のあるパートの A 系の型とフレーズ |
| 生成側・実音側 | アレンジで選別する前のイベントと、した後のイベント。生成側は全パートを含む |

## 和声

| 用語 | 意味 |
| --- | --- |
| キー（`Key`） | 主音。旋法はナチュラルマイナーに固定 |
| 初期キー（`initialKey`） | 最初のサイクルのキー。2つ目以降のサイクルのキーはここからの移調の幅で決まる |
| 移調の幅（`FifthsFromInitial`） | 初期キーから五度圏を属調の向きに何歩進んだか |
| 骨組み（`MainSkeleton`・`TransitionSkeleton`） | 表から選ぶ4つのダイアトニックコード |
| 主進行・転換進行 | A 系で鳴らす進行と、B で鳴らす進行 |
| 色付け | 骨組みのコードに、借用和音への置き換えとテンションを加えること |
| 構成音（`ChordTone`） | コードのルート・3度・5度・7度 |
| テンション（`Tension`） | 9度・♭9度・11度・♯11度・13度。上モノだけが鳴らす |
| 借用和音 | 同じ主音を持つ別の旋法から借りたコード。IV7・♭IImaj7・V7 |

## 音程のあるパート

| 用語 | 意味 |
| --- | --- |
| サブベース（`sub`） | 低域の骨格を作るサイン波のベース |
| リースベース（`reese`） | 中域を細かく動くデチューンしたベース。ドロップだけで鳴る |
| スタブ（`stab`） | コードを短く切って鳴らす上モノ |
| パッド（`pad`） | コードを2bar 全体で鳴らす上モノ |
| 型（`SubStyle` など） | パートのリズムの型。32bar ごと（A 系はサイクルごと）に選ぶ |
| 音色（`ReeseTimbre` など） | リースベース・スタブ・パッドのシンセの設定の表の名前。サイクルごとに選ぶ |
| ボイシング（`Voicing`） | 同時に鳴らす音の並び。低い順 |

## 再生と音

| 用語 | 意味 |
| --- | --- |
| セッション（`PlaybackSession`） | 再生を始めてから停止するまで。再生中か一時停止中のどちらか |
| 再開位置（`ResumePoint`） | 一時停止した時点でまだ鳴っていなかった最初のステップ |
| ゲート | 出力の直前で音を切る Gain。停止と一時停止で閉じる |
| チャンネル（ストリップ） | ミキサーの1行。音量・パン・センド・ミュート・ソロ |
| ダッキング | キックに合わせて、サブベース・リースベース・パッドの音量を下げること |
| リバーブスロー | ドロップやブレイクダウンの直前の最後のスネアを、リバーブに大きく送ること |
| ライザー | ビルドの間に上がり続けるノイズ |
| スイープ | イントロのローパスと、ビルドのハイパスの動き |
| インパクト | ドロップの頭で鳴らす、ピッチの下がる合成音 |
| オートメーション | FX のイベントから求めた、パラメーターの時間変化の点列 |

## 生成の仕組み

| 用語 | 意味 |
| --- | --- |
| シード（`Seed`） | 32bit の符号なし整数。展開を決める乱数の出発点 |
| タグ（`TAG`） | シードから用途ごとの乱数列を派生させるための整数 |
| コンテキスト（`Context`） | 2bar ごとに生成器へ渡す、位置・役割・進行・キーなどの情報 |
| コンダクター | 2bar の通し番号から `Context` を作るもの |
| アンサンブル | コンダクターと全生成器を決まった順に呼び、2bar 分のイベントを返すもの |
| ラッチ | パラメーターの値を、決まった境界でだけ読み取ること |
| 調整用の数値（`GenerationTuning`・`SoundTuning`） | 試聴で詰める確率・重み・周波数など。設定ファイルで上書きできる |
| 設定ファイル（`config.json`） | 初期値と調整用の数値を上書きする JSON |
| 変化率（`m2`・`m8`・`m32`） | 2bar・8bar・32bar の変化の量のパラメーター |
