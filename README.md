# GenDnB

## 概要

GenDnB は、パラメーターを設定するだけでドラムンベースのビートをランダムに展開しながら永久に鳴らし続ける、ブラウザ向けのジェネレーティブ・シーケンサーです。完全なランダムではなく、2bar・8bar・32barそれぞれの単位でまとまりのある展開になるよう変化率を制御します。

## 特徴

- **永続的な音楽再生**: 再生ボタンを押せば、ユーザーが止めるまで新しいパターンを生成し続けます。
- **階層変化**: 2barの基本ループ、8barのセクション、32barのフレーズという3階層で、変化の種類と量を使い分けます。
- **反復パターン**: 各区間を、基準となる区間に対する関係（反復・変奏・転換）として決め、シード付き乱数で生成します。反復は同じ形で再現され、変奏と転換が要所で変化を生みます。
- **DnBらしさの維持**: ステップごとの重み表とパートごとの変異しやすさにより、ランダムでもジャンルの文法を崩しません。
- **拡張前提の設計**: 全パートが共通インターフェースの生成器として実装され、ベース・ウワモノ・FXを後から追加できます。
- **再現性**: シード値を保存すれば、同じ展開をもう一度聴けます。

## 技術スタック

| 領域 | 採用技術 | 理由 |
| --- | --- | --- |
| 言語 | TypeScript | イベント型やコンテキスト型を厳密に定義するため |
| ビルド | Vite | 開発サーバーが速く、静的アセットの扱いが簡単 |
| 音声 | Tone.js（Web Audio API 上） | Transport による先読みスケジューリングに加え、フェーズ2以降の合成音源・エフェクトをそのまま使えるため |
| タイマー | Tone.js の Worker クロック | メインスレッドの負荷でテンポが揺れるのを防ぐため |
| 乱数 | 自前実装の sfc32（シード派生は splitmix32） | 再現性と階層ごとのシード派生のため |
| UI | Vanilla TS（MVP） | MVP の UI は最小限のため。拡張時にフレームワーク導入を再検討 |
| テスト | Vitest | 生成器を音声なしで単体テスト・統計検証するため |

## ディレクトリ構成

生成（何を鳴らすか）と再生（いつ鳴らすか）をディレクトリレベルで分離しています。生成器は音を出さず、イベント列だけを返します。

```
gendnb/
├── public/samples/drums/    # kick, snare, hat, ghost の WAV
├── src/
│   ├── engine/
│   │   ├── transport.ts     # Tone.Transport の設定、2bar ごとの生成要求
│   │   └── audio.ts         # Tone.js の音源、サンプル読込、再生
│   ├── structure/
│   │   ├── conductor.ts     # 小節位置 → コンテキスト
│   │   └── form.ts          # 区間の関係（反復/変奏/転換）
│   ├── generators/
│   │   ├── types.ts         # Generator インターフェース、イベント型
│   │   └── drums/
│   │       ├── weights.ts   # ステップ重み表
│   │       ├── mutate.ts    # 変異
│   │       ├── ornament.ts  # 装飾
│   │       └── fill.ts      # フィル
│   ├── random/rng.ts        # シード付き PRNG、シード派生
│   ├── params/store.ts      # パラメーター管理
│   ├── ui/                  # 操作パネル
│   └── main.ts
├── tools/simulate.ts        # オフライン長時間生成と統計出力
├── tests/
└── docs/                    # 要件定義書、ロードマップ
```

## セットアップ

必要環境は Node.js 24 以上と、Web Audio API に対応したモダンブラウザ（Chrome / Firefox / Safari / Edge の最新版）です。

```bash
git clone <repository-url> gendnb
cd gendnb
npm install
npm run dev
```

ブラウザの自動再生制限により、音声は画面上の再生ボタンを押した時点で開始されます。

## 開発コマンド

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 本番用ビルド |
| `npm test` | 単体テストを実行 |
| `npm run simulate -- --bars 4096 --seed 42` | 音声なしで長時間生成し、密度・反復率などの統計を出力 |
